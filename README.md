# 🛒 E-commerce Product & Price Scraper

A robust Python automation tool built with `BeautifulSoup` and `requests` to extract e-commerce product details—including titles, prices, and descriptions—directly into a clean and organized CSV format.

## ✨ Key Features
- **Smart Headers:** Mimics a real browser User-Agent to prevent blocking.
- **HTML Parsing:** Efficiently navigates DOM elements to extract targeted product info.
- **Automated Export:** Automatically saves structured data into `ecommerce_products.csv`.
